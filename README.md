# 💧 DI Water Monitoring System

## Project Overview

This project is a real-time DI Water Monitoring System developed to monitor water parameters through a web-based dashboard. The system provides continuous monitoring and visualization to support efficient industrial operations.

---

## 🎯 Objectives

- Monitor DI water parameters in real time
- Provide dashboard-based visualization
- Improve monitoring efficiency
- Reduce manual checking activities
- Support data-driven decision making

---

## 🛠 Technologies Used

### Hardware
- ESP32
- Water Monitoring Sensors
- Communication Module

### Software
- ASP.NET Core
- Razor Pages
- HTML
- CSS
- JavaScript
- Visual Studio

---

## ⚙️ System Workflow

1. Sensors collect water parameter data.
2. ESP32 processes the sensor readings.
3. Data is transmitted to the monitoring dashboard.
4. Dashboard displays real-time information.
5. Users monitor system status through the web interface.

---

## 🚀 Key Features

- Real-time monitoring
- Web-based dashboard
- Industrial monitoring application
- Live parameter visualization
- User-friendly interface
- PDF report generation
